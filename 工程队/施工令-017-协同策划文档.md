# 施工令-017 · 协同策划文档（制作人 2026-08-07 23:36 批准即做）

裁决：可视化+可协同编辑的策划文档集成进监制台；编辑职权=制作人（UI）/总监（文件/API）/策划（文件）；每块标注作者可视区分；保存即 git 页史。

## 文档格式（文件先行，agent 友好）

`*.codoc.md` 落项目仓 `Docs/SLG/策划文档/`：正文为 markdown，块与块之间用元数据注释分隔：
`<!--blk id=b12 作者=制作人|总监|策划 时=ISO-->`
块=一段/一表/一节。解析容错：无元数据的整段视作单块（作者=未知）。

## 范围（apps/studio）

1. **lib/codoc.js**：parse/serialize/块级增删改；save 时仅 `git add 该文件` + `git commit -m "协同文档 <文件名> · <作者>编辑"`（项目仓路径推导同 docs.js；git 失败不阻塞保存，回执警示字段）。
2. **API**：`GET /api/codoc?zone=策划案&file=…`（结构化块列表）；`POST /api/codoc`（块级操作：改/增/删/移，body 含块 id 与新文本，作者一律=制作人——UI 唯一写者）。
3. **wiki 策划案区编辑模式**（public/app.js）：`.codoc.md` 文档进阅读页有「编辑」开关：块级就地编辑（textarea 朴素版）、块间「+ 加一块」、删块带确认；**作者可视**：块左缘色带（制作人=金 bronze / 总监=墨 ink / 策划=青）+悬停显作者与时间+顶部图例；只读态同样显作者色。渲染复用 wkMd()。
4. **种子文档**：把 `Docs/SLG/策划文档/TK-总体策划-可视化.html` 的内容转写为 `TK-总体策划.codoc.md`（全部块 作者=总监，内容忠实迁移：基石/核心循环/对标/系统框架表/MVP/三取舍/决议记录），旧 html 移除；转写落 TK 仓并 git 提交（此为本单唯一 TK 仓写动作，单文件）。
