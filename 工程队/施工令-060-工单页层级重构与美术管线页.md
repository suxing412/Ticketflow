案源：制作人 2026-08-19 17:36–18:41 逐轮定稿。起点是「监制台能不能给一份可视化工作进程，包括项目管理也是」；经三轮收敛，痛点锁定在两条（制作人原话选项 乙/丁）+ 一条新需求：

- **乙 · 回头看不了**：单一落袋就从视野消失，想复盘「上周那批为什么慢」没地方看；
- **丁 · 项目管理层面看不见**：整条管线做到哪了、还剩多少、按现速什么时候完，无任何视图（`管线/P-1~P-4` 是正经实体、有注册表 `lib/pipelines.js`，却零视图——本次盘出的洞）；
- **美术管线生成进度不可见**：artgen 走本机 ComfyUI（`127.0.0.1:8188`，`tools/artgen/artgen.js:15-16`，未启动自动拉起），跑到第几步只有命令行里看得到。

制作人对第一版「一行一实体的折叠树」明确否决：**要卡片、要钻取**（「不要这样一行一行，给我放卡片」「点击管线卡片之后进入到专项层级」）。对现专项页的评价是「看得这么丑」——经复盘，丑因有三：卡片高度参差（S-1 子单撑出滚动条）、顺序非按编号（实况是 S-2/S-1/S-3）、目标描述吃掉半张卡。

写区：`apps/studio/public/app.js`、`public/style.css`、`server.js`（新增聚合与 ComfyUI 代理端点）、`lib/`（新增聚合模块）、`test/`。

## 要件

### 一、页签重排（净增 1 个：11 → 12）

1. **现「工单」页改名「看板」**（按状态分列的作业面，本令**不改其内容与行为**，只改页签名与路由别名；旧 `#/board` 书签须继续可达）。
2. **新「工单」页 = 组织结构面**（层级钻取，见要件二）。
3. **「专项」页签撤除**，其内容并入新「工单」页第二层；`#/specials` 旧书签转向新工单页。
4. **新增「美术」页签**（见要件四）。
5. 页签顺序：总览 / 想法 / **工单** / **看板** / 流程 / 队列 / 在途 / 决策台 / Wiki / 项管 / 报表 / **美术**。

> 分工口径（制作人定）：**工单页管归属（谁属于谁），看板页管流转（谁在哪一态）**。

### 二、新「工单」页 · 两层卡片钻取

**第一层 · 管线卡片**（`管线/P-*.md` 注册表全量，栅格排布 `minmax(238px,1fr)`）：
- 头：`P-n 名称` + 阶段徽章；
- 主数：落袋百分比（大字）+ `已落袋/总数`；
- 进度条**三段**：落袋（绿）/ 在制（蓝）/ 候人闸（琥珀）；
- 脚：`专项 N · 直属散单 M`、`在制 N`、`候闸 N`、`近 7 日 N 单`；
- **健康边框**（唯一的颜色语义，不做装饰）：阻塞（下游有单等本线）=红边；有在制=深边；静默 ≥5 日=灰边并在脚注标「静默 N 日」；
- 整卡可点，进入第二层。

**第二层 · 专项卡片**（面包屑 `← 管线 / P-n 名称`）：
- **按专项编号升序排**（S-1、S-2、S-3…）——硬要求，现专项页的乱序是制作人点名的丑因之一；
- 卡片内容沿用现专项卡片信息面（状态徽章、别名、目标、百分比、进度条、预计/实耗/偏差/token、收口报告与关账签字按钮）；
- **子单默认折叠**，折叠态只留一行摘要：`子单 N 张 · 完成 a · 归档 b · 待验收 c`；展开后**就地列出子单**（不再钻第三层），**点子单直达 `#/t/<id>` 工单详情页**（制作人定：「专项层就不用再点开了，展开子单列表，然后点击子单进入工单详情页」）；
- 目标描述**单行截断**（`text-overflow: ellipsis`），不换行撑卡；
- **「直属散单」虚线卡**固定排在末位：挂本管线但不属任何专项容器的单（如 TK-182），同样折叠+可展开+可点入详情。

### 三、复盘时间轴（并入「报表」页，不单开页签）

- 横轴真实时钟，一行一单，分段=各环节实耗（领单/执行/质检/验收/落袋各一色，返修与失败发用红段）；
- 数据源：工单 frontmatter（`领单时间`/`交付时间`/`更新时间`/`失败次数`/`自修次数`/`返修轮`）+ `journal/` 事件流水，**不新增写盘**；
- 默认窗口：**最近 20 单**（按单数比按时间稳，产量不均时不出空窗）；可切「本周」；可按管线/职能筛；
- 卡尺汇总行：落袋数、实耗中位、返修率、最耗环节占比、白烧次数（抖动重发/无判词重跑）；
- 用途口径：报表现有数字（返修率、估时准度）只给总量，时间轴补的是**是哪几张单、卡在哪一环**。

### 四、新「美术」页 · 常驻设施面

制作人裁定其实体属性（H52 实体分立律）：**美术管线不是管线**——「它本身没有完成的目标，它只承接需求交产出，是一个常驻的东西」。故不入管线卡片，独立页签。

- **ComfyUI 活体状态**：在跑 / 未启动（未启动**不报错**，显示状态与「artgen 会在首次调用时自动拉起」提示）；
- **当前任务**：通道名（`t2i-sdxl`/`t2i-klein`/`mesh-3d`）、第几张/共几张、**当前节点名 + 步数进度条**、已跑秒数、来源单号；
- **队列**：排队任务数与预估耗时；
- **本轮产出**：文件数与落盘目录；
- 取数：新增 studio 侧只读代理端点转发 ComfyUI `GET /queue`、`GET /history/{id}`（artgen 已在用 `/history`，见 `artgen.js:118-122`），进度用 ComfyUI WebSocket `ws://127.0.0.1:8188/ws` 或轮询 `/queue` 二选一，**由执行方实测选型并在回执写明理由**；
- 地址取 `artgen` 同源配置（`ARTGEN_COMFY_URL` / `_cfg.comfyUrl`，缺省 `http://127.0.0.1:8188`），**不得在监制台侧另写死一份**（多副本漂移是本周审计的头号病根）。
