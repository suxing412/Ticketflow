# 施工令-037 · 关键汇报事件链重构（制作人 2026-08-09 18:34 批准设计稿）

设计稿定稿：`工程队/设计稿-037-关键汇报事件链.html`（色值换语义令牌）。案源：制作人 18:31 点名——关键汇报每条都是断头账，「每一项都应该有回应：什么时候被委托起草/切单/送审/审过/派发、为什么派发、后续等待什么、状态怎么样」。

## 范围（apps/studio 项管页 关键汇报区 + 必要的 server 聚合）

1. **一单一链**：关键汇报由平铺事件行改为按单号归组的事件链卡——受托起草（带委托事由摘要）→ 切单完成呈审 → 总监审定稿（带审改摘要，如有 fm 改判）→ 放行/派发（带池与模型）→ 交产出（带耗时）→ 审检各站（初检/深检/核查/QA 轮次与结论）→ 返修/定夺/上呈（如有，带因由）→ 终态；**尾端恒有「现在等什么、等谁」行**（活单）或终态一行（完成/归档单）。
2. **数据聚合**：服务端按单号归组台账事件流水 + 工单 frontmatter 时间戳（初检/核查/QA/返修轮次/挂起/待引擎实证等既有结构位），透出 `/api/pm/*` 聚合端点或扩展既有接口——**纯读聚合，零新事件源、零调度语义改动**；事件链取「关键站」白名单（起草/定稿/放行/派发/交产出/审检结论/返修/定夺/上呈/终态），不把全量流水灌进去。
3. **交互**：状态徽章三档（绿=完成折叠一行/橙=在途/紫=等人闸）；点头行展开收起；完成单默认收起、活单默认展开；展开态跨刷新保持（localStorage）。
4. **活体**：与在途页同款 15s 轮询口径刷新活单链尾；「现在等什么」判定复用 lifecycle 状态语义（含 032 的 待引擎实证 停闸态）。
5. 双主题+860px；`npm test` 全量零回归（基线 37 套件 404 例）+聚合端点测试。
