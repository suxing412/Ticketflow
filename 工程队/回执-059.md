### 夹具第一版栽了一跤，值得记一笔

第一版按常规打 `quota.getRateLimits = async () => 夹具` 注入——**打不进去**：`checkGate` 调的是
模块**局部**的 `getRateLimits`，不是 `module.exports` 上那个。结果那一版夹具的 50 格 checkGate
全是**真去拉了本机 codex app-server** 的实况读数（本地零 token，未计费，但不可复现、也证明不了任何事）。

改法：拦 `child_process.spawn`，按 codex 的 JSON-RPC 脚本化回放夹具快照（`initialize` → `initialized`
→ `account/rateLimits/read`），于是两侧都走**完整取数路径**，比的是端到端判定而不是被掏空的半截。
顺带一条给后人的提醒：**想桩掉 quota 的取数，改导出面是不够的**——`server.js` 的 `STUDIO_STUB` 块
之所以有效，正因为它把 `checkGate` 本身也单独换掉了（`stub.test.js` 15 项照过，本令未动那一块）。

## 三、边界补测清单（要件 4）

包自测 16 项：前半把迁移带过来的老行为逐条钉死（窗口正名、双闸取严、fail-open、关闸口径），
后半是本令补的边界——

- **空快照**：`windowsOf` / `claudeWindows` 对 `null` / `undefined` / `{}` / `{primary:null}` /
  `{primary:{}}` / `{primary:{resetsAt:0}}` 一律空清单；`gateOf` 六种空态一律 fail-open 放行并写明原因；
- **未知池**（既非 codex 也非 claude 的形状）：`{五小时:{已用:88}}`、`{five_hour:{...}}`（蛇形原名不是
  本包输入契约，改写归取数方）→ 空清单，不猜不编；
- **单窗池**：codex 实机只有 `primary` 周窗 → 只出一条周条（不摆空的 5h 条）；claude 只有 `sevenDay`
  也能单独成立（次窗不依赖主窗）；
- **0 不是空**：`usedPercent: 0` 出条目、`fmtReset(0)` 是 1970 不是「未知」；`usedPercent` 缺失时
  `describe` 出 `?%` 而不是 `0%`——「不知道」和「零」是两回事；
- **label 三档边界**：360 分（6小时）/ 361 分（报分钟）/ 8999 分 / 9000 分（周）逐个钉死；
- **纯函数红线**：源码扫描断言包内**不出现 `require(` / `child_process` / `fs.` / `fetch(` /
  `process.env`**；同输入连调两次逐字节相同；输入快照不被就地改写；
- **导出面锁死七个**：`Object.keys` 全等比对——少一个，壳的形状校验就该当场判失败（下一条）。

studio 接线 11 项里值得点名的三格：

- `形状校验：解析到半截包（缺 gateOf）当场判失败进下一候选`——解析到个假货比找不到更坑；
- `失守态实测`（子进程、拦掉仓内相对候选）：`poolLock` 拿 99% 的快照**不锁、窗口为空**，
  journal 落「额度解读件失效」；紧跟一格**正常态对照**（同脚本同快照，包在位时照锁、流水干净），
  证明差异确由失守带来；
- `关闸态（gatePercent=0）不发起查询`：子进程数 `spawn` 调用次数 = **0**，判定仍是「守门已关闭」。

## 四、这次认下的一个代价（写在明处）

解读件三候选全失守时，空实现给的是**空窗口 + fail-open**，即那段时间**额度锁恒不锁**。
这与既有纪律同向（quota 从来是「查询失败一律放行，绝不因查询挂了卡死管线」），但代价比 budget 那次大：
budget 失效是「不落账」，quota 失效是「刹车片没了还在跑」。故响亮化按 046 三层做足了两层：
控制台一行 + journal 一条（原文写明「额度锁恒不锁」，运维一眼知道此刻在裸奔）+ 对象上的
`失效 / 失败因` 与 `失效位()`。

**第三层（`/api/gates` 挂 `quota失效` 位 + 参数页红标）本令没做**——`server.js` 与 `public/app.js`
不在写区。`失效位()` 已按 `budget-resolve.失效位` 同形备好（返回 `{quota失效, quota失败因}`，
正常命中时空对象），server 那侧展开一行即可。**建议下一张单一并做掉**，接法可原样抄 046。
