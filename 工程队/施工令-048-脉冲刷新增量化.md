# 施工令-048 · 脉冲刷新增量化（频闪根治）

案源：制作人两次实报「监制台频闪」（2026-08-11 晚、2026-08-12 15:38）。根因：`public/app.js` 末部 3s 脉冲轮询在令牌变化时调 `route()` 整页重建；管线繁忙期（QA 重试/journal 连环写）令牌逐拍皆变 ⇒ 整页每 3s 重绘一次，肉眼即频闪，且滚动位/展开态全丢。

写区：`apps/studio/public/app.js`（+必要的 `style.css`）。禁碰 server/lib。

## 要件

1. **脉冲响应改增量**：令牌变化不再整页 `route()`；按当前视图做**原地局部刷新**（工单板/在途/详情/流程/队列各自的刷新函数只更新数据区，不重建骨架）。做不到细粒度的视图，最低限度保证：刷新前后**滚动位置、折叠/展开态、输入焦点**三态不丢。
2. **繁忙节流**：脉冲连续变化时合并——整页级重建（若仍有兜底场景）至少间隔 30s，且页面可视区有用户交互（滚动/输入/悬停菜单开启）时顺延。
3. **详情页计时器与脉冲解耦**：详情页已有 1s 计时器原地更新，脉冲刷新不得打断它或引发闪烁。
4. **测试**：pulse 处理逻辑抽可测函数（输入=令牌变化序列+当前视图态，输出=刷新动作类型），单测覆盖：忙时合并、交互顺延、局部刷新选择；`dialogscan` 等既有测试零回归，全量 npm test 绿。

## 验收

逐条自证；回执 `工程队/回执-048.md` 附繁忙模拟（脉冲每 3s 变，持续 2 分钟）下的刷新动作日志（整页重建次数 ≤4）；git 提交本令文件面；不打包（总监统一换装）。
