## 五、预算闸的接入口径（下次改它之前先读这段）

**刻意没改 `dispatch.poolFrozen` 的签名。** 预算冻结结果由调用方
（`runner.tick` / `server` 的 `/api/gates` 与 `/api/pm/roster`）用 `budget.并入()`
合进 `gatesInfo`，于是池序降级、编制快照可用性、UI 三处自动跟着走，零额外接线。

配置段（未配 = 不管，绝不臆造上限）：

```json
"预算": {
  "池": { "claude-key": { "日token": 2000000, "月额": 80 } },
  "价目": { "claude-key": { "输入": 3, "输出": 15 } }
}
```

价目单位是每百万 token 的金额；缓存读默认按输入价 1/10 估。
没配价目表时金额上限自然失效，只剩 token 口径——**算不出费用就不许判超**。
