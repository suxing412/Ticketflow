# 施工令-019 · 评审台红队角色化（H91 配套，微单）

## 范围（套件/评审台/review.js + apps/studio/lib/pm/brain.js）
1. review.js 评审提示词升级为**立场卷制**：各厂按序领卷轮换——可行性红队（找实现不了的点）/不变量红队（找清单漏掉的承重约束）/成本红队（找烧穿工期额度的暗礁）；单厂在席时领全部三卷。**击杀制**：每卷必须尝试构造具体失败场景（输入/状态/时序），构造不出要明说「未能构造击杀」——这句话就是通过证据；泛泛意见不算完卷。输出格式保持兼容（表格+意见条目），条目加「卷别」与「击杀/未杀」标。
2. brain.js 方案单/调研单条款同步一句：评审台为红队立场卷制，验收标准的评审证据项含击杀结论。
3. 测试/取证：伪造多厂应答实测立场卷轮换与单厂全卷；grep 验证 brain 两处；apps/studio npm test 全量护身（32 套件 274 用例基线）。
