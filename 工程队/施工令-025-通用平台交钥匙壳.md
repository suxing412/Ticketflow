- `server.js`：最小 HTTP 服务（端口 4370，避开监制台 4270/心跳）——静态托管 public/ + `/api/health` + `/api/watchtower`（读心跳戳给在岗灯）。**不含任何工单/职能/派发语义**——执行器接线只到「providers 注册表可枚举、可发一条 echo 级测试调用（桩模式）」为止，真实调度是他自己长的。
- `public/`：最小 UI 壳——一页仪表盘：平台名+版本、providers 枚举表、**瞭望塔在岗灯**（绿=心跳新鲜，红=离岗+提示拉起命令）、未读账本列表（读 jsonl）。样式朴素干净即可，双主题不要求。
