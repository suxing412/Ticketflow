# 施工令-021 · 制作人裁决权补全（挂起机制+按钮补全，制作人 2026-08-08 22:11 批准）

案源：TK-105/TK-S2 类「整个不对」的单，制作人无挂起/冻结按钮可用（总监土法=往文件写搁置令）；专项父单详情页连废弃按钮都不渲染。

## 范围（apps/studio）

1. **挂起机制**（lib/lifecycle.js + runner/dispatch/patrol）：`fm.挂起`（时间戳+操作者）；新 API 动作 `挂起`/`解挂`（任何非终态单可挂，解挂原状态原位复活）；派发/领单/质检/初检/核查/仲裁/巡检告警/零派发计数**全部跳过**挂起单；测试覆盖各环节跳过+解挂复活。
2. **按钮补全**（public/app.js 详情页 ops + 决策台）：挂起/解挂（带确认）、废弃——**专项/父单同样渲染**；父单挂起时弹选项「仅父单 / 全树挂起（连带子单）」。
3. **可视**：挂起单全站置灰+❄ 徽标（工单池卡/树形行/流程节点/在途），详情页顶部「已挂起」横幅（挂起人+时间+解挂按钮）。
4. 迁移：扫描各状态目录 frontmatter 兼容（无挂起字段=未挂）；无历史迁移负担。

## 不要做
- 不动已归档语义；不做定时自动解挂；不打包不提交；AI-GameStudio 不碰。

## 验收标准
- [ ] 挂起单在派发/审检/巡检全环节被跳过（测试逐环节）；解挂后原位复活可被正常调度
- [ ] 详情页/决策台按钮齐（含专项父单）；父单全树挂起连带生效（实机取证）
- [ ] 全站 ❄ 置灰可视四处取证；`npm test` 全量 0 失败（基线 35 套件 288 用例）
- [ ] 完工纪要逐条证据
