# D 级 · 惯例与默认值

> 修改门槛：实践中演化，复盘时升降级（被反复依赖的惯例经决议可升 B 级）。
> 本典收录"不成文就会丢，但还不到法律级"的实践约定。

## 生产惯例

- **首样保留**：每类新资产第一件走保留验收由制作人定调，同批后续可委托（H43④）。
- **收口单**：每系统每阶段的最后一张子单为收尾单（装配拼装+回归，保留验收）。
- **占位命名**：占位资产带 `placeholder_` 前缀，正式资产不带；文件名英文小写下划线。
- **概念图规范**：供 3D 化的概念图 = 白底、单体居中、3/4 视角，一物一图。
- **可复现性**：生成类产出（图/模型）的参数（seed/通道/模型/LoRA）随回执记录。
- **回执消耗行**：实际消耗含机器可读行 `约 N tokens`，供报表聚合。

## 工程惯例

- **显存水位**：GPU 任务留余量不压线（32G 卡工作集 ≤26G 为宜）——压线触发共享内存回退是断崖不是斜坡。
- **监工超时 ≥ 任务量级**：长任务的守望超时按实际量级放宽，勿让监工先于任务下班。
- **沙箱冒烟**：改动经独立沙箱工作区冒烟后再上生产（`STUDIO_ROOT` 指临时根）；绝不向生产环境播种演示数据。
- **预估口径**：agent 执行速度比人类预估快一个数量级，预计时间按机器速度校准（消耗报表实测）。
- **中文提示词走 stdin**：无头 CLI 的中文指令经 stdin 传递（argv 乱码）；代理 env 随子进程注入。
