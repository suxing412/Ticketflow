# @ticketflow/role-protocol-templates · 岗位协议模板

六职能执行 agent 的**起步章程模板**：`通用.md`（铁律与完工报告格式）+ `策划/程序/美术/QA/装配` 各一份（写区与产出物边界）。

## 只留机制模板，协议正本各家私域

本包只收**机制条款**——一单一事、写区边界、回执契约这类跨项目通用的治理机制。**协议正本**（含项目命名、定制条款、实际编制的那份）在各部署方私域维护（如 AI-GameStudio 私仓 `监制台/岗位协议/` 的 TK 定制版），改了下一单立即生效，永不回流公开仓（A 级发布纪律：公开仓只有通用默认）。

## 消费方

- `apps/studio` 首次运行向导（`lib/setup.js`）：源码布局优先从本包拷章程，拷不到落内置最小章程；
- `套件/打包套件.ps1`：打包骨架时把本包六份 md 铺进 `骨架/岗位协议/`；
- 新部署方：拷走改名即用，机制条款保持、项目内容自加。

## 迁移

原址 `套件/岗位协议模板/`（施工令-024 迁入，旧目录留 `已迁移.md` 指路）。
