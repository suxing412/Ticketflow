# @ticketflow/skill-templates · 执行技能模板

执行会话的两份流程化 SKILL 模板（H66 强制）：

- `pre-work/SKILL.md` —— 开工检查：评估可行性 → 环境体检 → 定测试基线 → 开工声明 → 长等待叙述（进度打点 H100 已退役）；
- `post-work/SKILL.md` —— 收工汇报：测试证据 → 回执契约 → 工单评分 → 收尾卫生。

## 结构：通用契约核 + 产品叠加层

本包只放**通用契约核**——跨项目通用的流程与红线（评估回呈制、基线对照、空壳回执判不过、禁 tail 截尾推数等）。**产品叠加层**（具体工程的取证细则，如 TK 仓 Unity 工程的 `unity-evidence` 取数口径）由各部署方在自己私域补充，与本核配套使用，不回流本包。

改本包 = 改所有部署方的执行契约，须走正常 PR 互审；产品专有内容（项目命名/定制条款）不得写入。

## 部署

把两个子目录拷进执行会话的技能目录（如 `~/.claude/skills/`）即用；文内引用的通道命令按部署方实际路径替换。

## 迁移

原址 `套件/执行技能模板/`（施工令-024 迁入，旧目录留 `已迁移.md` 指路）。
